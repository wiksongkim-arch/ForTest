# ForTest 安装包隐私与配置隔离审计

## 数据边界

- 安装目录只包含原生程序、运行库、Codex 官方运行时及必要元数据。
- 普通用户配置统一写入 `%LOCALAPPDATA%\ForTest\UserData\data`。
- AI API Key、MCP 地址和 Jenkins Token 只写入 Windows 凭据管理器，JSON 中仅保存非密钥字段。
- 生成结果、任务记录、日志、下载的 Codex 版本均位于用户数据目录，不使用源码目录或安装目录。
- EIM OAuth/DWS profile、事件 inbox/outbox、去重状态和临时媒体只位于 `%LOCALAPPDATA%\ForTest\UserData`；安装包和源码快照不得包含任何连接 profile 或事件内容。
- EIM 配置导出不包含凭据；日志和样例执行结构化脱敏，媒体按任务策略清理，存在未完成投递时最长保留 30 天。

## 已消除的问题

- 清除了产品默认值中的实际钉钉模板、文档模板和输出目录地址；新用户首次安装显示为“未配置”。
- Web 与原生端共用用户数据路径，旧版 `data/settings.json` 不再作为运行时设置入口。
- 启动日志与托管进程状态移出源码目录，统一进入用户数据目录。
- PyInstaller 不再额外复制第三方 Python 源码和 `__pycache__`。

## 构建门禁

`windows_native/package_privacy.py` 在构建中执行两次：

1. 构建前检查源码默认值、工作区用户文件、PyInstaller 收集范围和安装器来源。
2. 构建后解析 PyInstaller 内部代码归档，检查固定业务节点、明文密钥形态、绝对用户路径、当前环境/凭据管理器中的受保护值，并检查安装目录文件清单。

报告只记录命中类型和来源标签，绝不写出被检测的密钥或业务配置明文。任一检查失败都会中止安装包生成。

## 安装与卸载

- 安装器仅递归复制 `windows_native/dist/ForTest`。
- 默认卸载保留用户配置和生成结果；用户明确选择“同时删除全部用户数据”时才删除用户数据及凭据。
- 最终验收必须同时检查 PyInstaller 目录、安装后的目录和安装启动诊断。

## 公开仓库边界

- Git 只保留长期有效的产品、架构和安全文档。
- Codex/开发助手生成的日期化计划、验收记录、一次性审计与版本交付报告仅保存在本机忽略目录。
- `.idea/`、`.vscode/`、`.codex/`、`.codex-work/`、构建目录、覆盖率报告、运行日志、用户配置和 `预删除/` 均不得强制加入提交。
- 正式公开仓库前仍需检查 Git 作者邮箱与历史提交；当前文件被忽略或删除不代表旧提交中的内容自动消失。
